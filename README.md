# 🍕 Pizzaria Delícia - Sistema de Pedidos Online

Um sistema elegante e moderno para pedidos de pizza online, com interface responsiva e animações suaves.

## ✨ Características Principais

- **Design Moderno**: Interface com gradientes vibrantes e animações suaves
- **Totalmente Responsivo**: Funciona perfeitamente em desktop, tablet e mobile
- **Experiência do Usuário**: 
  - Cards de pizza com efeitos hover
  - Modal interativo para seleção de tamanho
  - Carrinho lateral com atualização em tempo real
  - Animações e transições fluidas
  
## 🎨 Destaques do Design

- Gradientes modernos em roxo e azul
- Cards flutuantes com sombras suaves
- Botões com efeitos hover e animações
- Sistema de cores harmônico
- Ícones emoji para melhor visualização
- Tipografia elegante com Hepta Slab e Lato

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3 (Gradients, Flexbox, Grid, Animations)
- JavaScript Vanilla
- Responsive Design

## 📱 Como Usar

1. Abra o arquivo `index.html` em seu navegador
2. Navegue pelas pizzas disponíveis
3. Clique no botão "+" para adicionar ao carrinho
4. Escolha o tamanho desejado
5. Ajuste a quantidade
6. Clique em "Adicionar ao carrinho"
7. Acesse o carrinho pelo ícone 🛒 no topo (mobile) ou lateral (desktop)
8. Finalize seu pedido

## 🎯 Funcionalidades

- ✅ Listagem de pizzas com imagens e descrições
- ✅ Seleção de tamanho (Pequena, Média, Grande)
- ✅ Controle de quantidade
- ✅ Carrinho de compras dinâmico
- ✅ Cálculo automático de subtotal
- ✅ Desconto de 10% aplicado
- ✅ Total calculado automaticamente
- ✅ Interface responsiva para todos os dispositivos
